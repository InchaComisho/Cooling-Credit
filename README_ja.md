# Cooling Credit / クーリングクレジット / رصيد التبريد

[English Version](README.md)

**クーリングクレジット（Cooling Credit）**は、成果ベースの気候経済を描くSFプロジェクト兼概念フレームワークです。環境に優しいと主張することではなく、測定可能な温度を実際に下げることで価値が生まれる世界を扱います。

## 日本語概要

**クーリングクレジット**は、「温暖化対策を“結果ベース”で評価したらどうなるか？」という発想から生まれた物語です。

この世界では、環境への努力そのものではなく、**実際に温度を下げたかどうか**が価値になります。かつてのカーボンクレジットは、排出削減の証明や書類上の取引に依存していました。しかし、その仕組みが偽装や形だけの環境対策によって崩壊したあと、人類はより単純で残酷な基準を選びます。

それが、**Cooling Credit（CC）**です。

冷やした分だけ評価される。温度差、湿度、排熱、反射率、蒸発、影、都市構造、人の移動までが数値化され、冷却効果として通貨化される。主人公・相馬ユウトは、猛暑の街でそのルールに触れ、やがて「熱」を敵ではなく攻略対象として見始めます。

本作は、気候危機、都市設計、冷却インフラ、行動経済、ゲーム的最適化を、物語として直感的に描く試みです。
